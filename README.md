# nitinog10/Beta-20

Comprehensive AI-driven travel advisory system for personalized trip planning in India.

## About

BharatTrip AI offers travelers in India a smart, personalized travel advisory service. It provides cultural insights, smart planning, and tailored trip recommendations.

## Features

- Personalized trip recommendations
- Cultural insights for destinations
- Smart planning tools
- Automated environment setup
- Backend health checks
- API testing scripts
- Detailed documentation and troubleshooting guides

## Tech Stack

- React (Frontend)
- Node.js (Backend)
- Batch and Shell Scripts (Automation)

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/nitinog10/Beta-20.git
   cd Beta-20
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up the environment:
   ```sh
  ./setup-env.sh
   ```

### Running the Project

- Start the React frontend:
  ```sh
 ./start-react.sh
  ```
- Start the Node.js backend:
  ```sh
  cd backend
  node server.js
  ```

## Project Structure

- **Root Directory**: Configuration files, automation scripts, documentation, HTML files, and image assets.
- **`backend/`**: Backend services, server logic, environment configurations, and API test scripts.
- **`Beach images data/`**: Images used for showcasing or integrating into trip planning features.
